# Maintenance Playbooks

這個資料夾記錄「網站日常維護」的具體操作流程——新增部落格文章、更新 CV
下載檔案等。目的是讓下次協助你更新時，不會漏掉容易忘記的細節（例如分類
要放對、CV 要加浮水印）。

跟 `.claude/specs/` 的差異：`specs/` 記錄「當初為什麼這樣設計」（一次性的
設計決策），這裡記錄「以後每次要做同一件事，具體步驟是什麼」（重複性的
操作流程）。

## 目前有的 playbook

- [新增部落格文章](adding-blog-articles.md) — 分類怎麼判斷、YAML 怎麼加、
  哪裡容易漏掉（Blog 頁面的分類篇數是手動維護的）
- [更新 CV 下載檔案](updating-cv.md) — Word 轉 PDF、加浮水印、換檔名、
  換連結的完整流程，附可重複使用的浮水印腳本
